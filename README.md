# Lister Rodriguez - Professional Portfolio

Interactive personal portfolio featuring full-stack credentials, AI projects, and an Obsidian-modeled **Constellation Graph** codebase visualization.

---

## Quick Preview (Local Testing)

You can preview the website before pushing to GitHub using any of these 3 easy methods:

### Method 1: 1-Click Launch (Recommended on Windows)
Simply double-click **`serve.bat`** in the project folder.  
It will start a local server and automatically open **`http://localhost:8000`** in your browser.

### Method 2: Via PowerShell
Run:
```powershell
.\serve.ps1
```
*(Or `powershell -ExecutionPolicy Bypass -File .\serve.ps1`)*

### Method 3: Direct File View (Zero Server Needed)
Double-click [**`index.html`**](file:///c:/Users/liste/Desktop/Portfolio/ListerRodriguezPortfolio/index.html) or [**`constellation.html`**](file:///c:/Users/liste/Desktop/Portfolio/ListerRodriguezPortfolio/constellation.html) to open directly in Google Chrome or Microsoft Edge.

## Exploring the Constellation Graph
Once the portfolio is open:
- Click the **`🪐 Constellation`** button in the navigation bar.
- Or click the floating **`🌌 Constellation Graph`** button in the bottom right corner.
- Or press the **`G`** key on your keyboard to switch view modes instantly.
- Click any node to open its metadata drawer, filter modules via the search HUD, or adjust physics simulation sliders.
